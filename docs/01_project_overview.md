# Goosebot Project Overview

## Goal

Create an autonomous RC vehicle capable of:

- Self navigation
- GPS positioning
- Indoor localization
- Obstacle detection
- Autonomous driving


## Main Computer

Radxa ROCK 5C

Operating System:

Debian 12 KDE


## Software

- ROS2 Humble
- robot_localization
- Nav2
- SLAM


## Development Stages

1. Hardware control
2. Motor control
3. Encoder feedback
4. Sensor integration
5. Localization
6. Autonomous navigation
